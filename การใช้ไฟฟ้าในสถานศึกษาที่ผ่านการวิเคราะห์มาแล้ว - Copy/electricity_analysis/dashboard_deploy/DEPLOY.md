# เตรียมระบบสำหรับวันแข่ง (แผน A ออนไลน์ และแผน B สำรองบนเครื่อง)

กติกาวันที่ 1 ให้ส่ง URL ระบบพร้อมคำแนะนำสั้น ๆ ภายใน 16:30 น. และห้ามแก้ระบบหลังส่ง
ผมทดสอบแผน B และการเปิดผ่านเครือข่ายภายในบนเครื่อง Linux แล้ว แต่ **ยังไม่ได้ทดสอบ Streamlit Cloud และ Windows จริง** จึงควรซ้อมตามขั้นตอนด้านล่างก่อนวันแข่ง

## ก่อนทำอะไร ให้รันตัวตรวจก่อน
```
python preflight.py
```
ตรวจ: Python 3.10 ขึ้นไป, ไลบรารีครบ, ไฟล์ข้อมูลครบ, คอลัมน์ที่ต้องใช้, คำนวณยอดรวมได้ ถ้าขึ้น FAIL ให้แก้ก่อน

## แผน A: ออนไลน์ (Streamlit Community Cloud)
1. สร้างที่เก็บ (repository) บน GitHub แล้วอัปโหลดโฟลเดอร์ `dashboard` ทั้งหมด (ข้อมูลอยู่ใน `data/` ขนาดรวมประมาณ 3 MB ไม่ต้องใช้ฐานข้อมูลภายนอกหรือรหัสลับ)
2. เข้า https://share.streamlit.io แล้วกด New app เลือก repository และ branch ตั้ง **Main file path** เป็น `app.py` (ถ้าอัปโหลดทั้งโปรเจกต์ ให้ใช้ `dashboard/app.py`)
3. ใน Advanced settings เลือก Python 3.12 (เวอร์ชันที่ทดสอบ) ระบบจะอ่านไลบรารีจาก `requirements.txt` ในโฟลเดอร์เดียวกับไฟล์หลัก
   - ถ้าติดตั้งไม่ผ่าน ให้ลองแทนที่ด้วยเนื้อหาของ `requirements-tested.txt` (เวอร์ชันที่ตรึงไว้)
4. เมื่อได้ URL ให้เปิดจากโทรศัพท์หรือเครื่องอื่น ตรวจว่าทุกเมนูและปุ่มดาวน์โหลดทำงาน
5. ระบบไม่มีหน้าล็อกอิน ส่ง URL ให้กรรมการได้ทันที พร้อม `QUICK_GUIDE.md`
6. แอปที่ไม่มีคนเปิดนานจะหลับ **ให้เปิดหน้าเว็บทิ้งไว้ก่อนกรรมการตรวจ** เพื่อไม่ให้ช้าตอนเปิดครั้งแรก

## แผน B: สำรองบนเครื่อง Windows
1. ติดตั้ง Python 3.10 ขึ้นไปจาก python.org (ติ๊ก Add python.exe to PATH) ล่วงหน้า และต่ออินเทอร์เน็ตตอนรันครั้งแรกเพื่อติดตั้งไลบรารี
2. ดับเบิลคลิก `run_dashboard.bat` (สร้างสภาพแวดล้อม `.venv` ติดตั้งไลบรารี รัน `preflight.py` แล้วเปิดระบบที่ http://localhost:8501)
3. หรือพิมพ์เอง:
```
cd dashboard
python -m pip install -r requirements-tested.txt
python -m streamlit run app.py
```
4. ให้เครื่องอื่นในเครือข่ายเดียวกันเปิดได้: รัน `run_dashboard.bat --server.address 0.0.0.0` แล้วดู IP ด้วย `ipconfig` เปิดที่ `http://<IP>:8501` (อาจต้องอนุญาตผ่านไฟร์วอลล์ Windows ครั้งแรก)

## เวอร์ชันและข้อจำกัด
- ทดสอบกับ Python 3.12 และเวอร์ชันใน `requirements-tested.txt` (ติดตั้งจากศูนย์แล้วผ่านบน Linux) ส่วน `requirements.txt` เป็นช่วงเวอร์ชันขั้นต่ำที่ยังไม่ได้ทดสอบทุกเวอร์ชัน
- Path ทั้งหมดใช้ `pathlib` และไฟล์ CSV อ่านด้วย `utf-8-sig` จึงไม่ผูกกับระบบปฏิบัติการ แต่ยังไม่ได้ทดสอบบน Windows จริง
