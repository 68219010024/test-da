# คู่มือย่อสำหรับกรรมการ (ไม่ต้องล็อกอิน)

เปิดเว็บแล้วใช้งานได้ทันที ไม่มีบัญชีหรือรหัสผ่าน เมนูอยู่ด้านบนของหน้า

**เมนูหลัก 5 กลุ่ม (ด้านบน)**
1. **ภาพรวม**: ตอบ 4 คำถามสำคัญ (ใช้ไฟทั้งหมดเท่าไร / สูงสุดเมื่อไร / พื้นที่ใดสูงสุด / พื้นที่ใดควรตรวจสอบเพิ่มเติม) และคำตอบสำคัญที่คำนวณอัตโนมัติ
2. **วิเคราะห์เชิงลึก**: สถิติเบื้องต้น, จัดอันดับ, เจาะลึก (อาคาร > ห้อง > ช่วงเวลา), นอกเวลาและวันหยุด, ความสัมพันธ์ (คน แอร์ อากาศ)
3. **คุณภาพข้อมูล**: ปัญหาข้อมูล วิธีจัดการ และก่อน-หลังทำความสะอาด
4. **Insight และแนวทาง**: สรุปผล 6 เรื่องพร้อมประโยคพูดนำเสนอ และปัญหาพร้อมแนวทางแก้ไข
5. **ข้อมูลและส่งออก**: ตารางข้อมูลและพจนานุกรม, ส่งออกข้อมูล, ข้อมูลที่ไม่มี, คู่มือย่อ

**ตัวกรอง** อยู่ใต้เมนู (กดเปิด "ตัวกรองข้อมูลและการตั้งค่า") ใช้กับทุกหน้า ปุ่ม "ล้างตัวกรอง" คืนค่าเริ่มต้น และสลับโหมดคำอธิบาย สั้น/เต็ม ได้ที่แผงเดียวกัน

**ส่งออก** รายงาน Excel 10 ชีต และไฟล์ CSV ที่ ข้อมูลและส่งออก > ส่งออกข้อมูล ไฟล์บันทึกเงื่อนไขการกรองไว้

**ข้อควรรู้**
- เกณฑ์ที่ทีมตั้งเอง (ไฟนอกเวลาเกิน 15%, ช่วงเย็นสูงกว่า 3 เท่า) ใช้คัดกรองเบื้องต้น ไม่ใช่มาตรฐานทางการ และปรับเปลี่ยนได้
- นอกเวลา = ชั่วโมงที่จำนวนคนเป็น 0 ตรงกับ 08:00-16:59 วันจันทร์-ศุกร์ในข้อมูล
- ข้อมูลจำลองปี 2025 มีปีเดียว ไม่มีอัตราค่าไฟ จึงรายงานเป็น kWh
- ใช้คำว่า "ควรตรวจสอบเพิ่มเติม" เมื่อข้อมูลไม่ระบุสาเหตุ และ "พบความสัมพันธ์" เมื่อไม่ได้พิสูจน์สาเหตุ

**ถ้าเว็บออนไลน์ติดขัด** รันบนเครื่อง: `pip install -r requirements.txt` แล้ว `streamlit run app.py` (หรือดับเบิลคลิก run_dashboard.bat บน Windows) รายละเอียดแผนออนไลน์/สำรองอยู่ใน DEPLOY.md
