# Tuidui Studio

A responsive Thai-language landing page built with React and Vite.

## Requirements

- Node.js 20.19+ or 22.12+

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```sh
npm run build
npm run preview
```

On Windows PowerShell, if script execution policy blocks `npm.ps1`, run the
same commands with `npm.cmd` (for example, `npm.cmd run dev`).
